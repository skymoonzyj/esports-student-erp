# 报名订单号

学员点击“提交报名申请”成功后生成订单号。仅选择项目、班型或教练时不生成。人工登记和接口导入形成的报名事项同样具有订单号。

编号格式为 `BM` + 中国日期 `YYYYMMDD` + 至少六位流水号，例如 `BM20260911000001`。流水号由 PostgreSQL 序列分配，全局递增，不按日重置；并发提交不会产生重复编号。事务回滚可能产生跳号，序号超过六位会继续增长。编号一经生成不可修改。

迁移 `0054_admission_order_numbers` 为所有历史报名补号，日期使用原报名创建时间的中国日期。原报名 ID、付款、退款、入班和分成关联均保留。一个报名的多笔付款和退款使用同一订单号，各笔交易仍保留独立记录 ID；支付渠道的 `external_order_id` 继续单独保存。

学员报名成功提示、最近申请、本人付款和退款明细，以及后台报名、收款、退款页面显示并支持复制订单号。后台报名事项和付款列表可按完整订单号精确查询，查询忽略首尾空白和英文字母大小写，并继续受现有角色和数据范围限制。订单号本身不能作为访问授权。

所有相关响应增加只读字段 `order_number`，请求操作仍使用原 UUID。接口包括报名申请、报名事项、正式报名、付款、退款以及本人付款与退款明细。列表通过关联查询读取订单号，不为每一笔付款额外查询编号。

升级前由 NAS 部署脚本备份数据库，升级后执行完整加密备份和隔离恢复验证，备份包含取号序列及其状态。
