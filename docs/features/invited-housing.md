# 我的邀请：只读住宿

超管通过“财务结算 → 分成管理 → 邀请机构负责人 → 查看负责人”（`/settings/revenue-share`），可添加多个现有登录账号或明确确认后移除负责人。必须同时满足真实超管角色及 `revenue_share.manage` 全局权限；机构创建人不会自动成为负责人。

负责人不需要财务或房态管理权限。在 `referrals.read_invited_housing` 功能权限允许且有有效邀请来源时，从首页或侧栏进入“我的邀请”（`/me/invitations`）。可选择全部授权来源、我邀请的或当前负责机构，按住宿状态筛选并分页；每页默认 20 人。只统计完成注册且已绑定邀请关系的受邀学员，不含待审核申请或多级邀请。

页面区分“暂无受邀人员”和个人“未安排住宿”。摘要显示当前房号、状态，以及单独标记的计划入住/离开和实际入住/离开日期；存在下一次预约时另列“下一次计划”。日期按中国时间显示 `YYYY-MM-DD`，计划结束日期不减一天。计划离开缺失显示“未确定”，长期入住显示“长期入住”，尚未发生的实际日期显示“—”。实际入住/离开必须由既有住房业务确认，计划日期到达不会虚构实际时间。

移除负责人、停用机构、禁用账号或显式禁止权限后，后续请求立即重新授权；旧组织参数得到不暴露组织存在性的私有 404。前端在显示期间最长 30 秒重新验证来源，页面回焦时也重验。重验未完成、断网或服务/权限错误时隐藏旧来源和名单；退出或账号切换清理缓存。已发送至其他设备的画面不能追溯收回，断网设备不承诺瞬间消失。停用邀请码不会删除已建立邀请关系。

本页面不提供安排入住、调房、退房、完整住宿历史或导出；不显示室友、证件、联系方式、备注、付款或分成金额。不请求财务接口，也不替代“我的分成”或邀请二维码权限。独立 API 仍执行关系与权限双重校验，菜单 capability 不是授权依据。

自动化浏览器验证使用合成资料和隔离测试库；桌面/360px 视口与焦点事件模拟不是物理手机或真实设备验收。发布由受控 NAS 脚本执行，配置默认空白，需超管明确指定负责人。
