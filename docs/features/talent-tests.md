# 天赋测试

## 用途与范围

天赋测试是 ERP 内的训练参考模块，不是医学、智力或职业测评。目录版本 `talent-training-v1` 固定包含反应速度、瞄准速度、顺序记忆、数字记忆、中文词语记忆、黑猩猩测试和视觉记忆七项；中文打字不属于本目录。页面不展示全球排名、官方百分位、IQ、职业潜力或七项平均总分。

每一轮只采用该轮服务器已保存的七项结果，不拼接历史最好成绩。第七项结果、完成状态和报告由服务端在同一事务中确认；客户端只在收到已完成轮次及服务端 `report_id` 后进入报告。

## 权限与隐私

- `talent_tests.take` 只支持 `self`，并且参加测试时还必须同时具备有效的 `talent_tests.read` 本人权限。
- `talent_tests.read` 支持 `global`、`self`、`family`、`person` 和 `assigned_class`。显式拒绝优先，普通管理员、教练或监护人身份本身不会自动产生入口。
- 未完成轮次只允许本人和具备全局读取能力的实际超管读取；其他授权读者只看到服务端过滤后的已完成报告。
- 越权对象和不存在对象统一按私有 404 处理。列表先授权过滤再分页，页面不根据 URL 参数自行推断所属关系。
- 报告只显示人员展示名、训练原始值、单位和规则快照，不显示手机号、身份证号、答案正文或其他联系方式。

前端菜单和按钮只是能力提示，不能替代服务端授权。权限新增、撤销和预览仍要求实际有效超管身份以及有效的 `permissions.manage`；仅有普通权限管理能力的账号只能查看本模块授权结果，不能操作本模块授权。

## 保存、重试与历史

创建轮次、提交结果和放弃轮次均使用账号及轮次隔离的稳定 UUID 操作键。待提交结果只保存在当前浏览器的 `sessionStorage`，最长 24 小时，不保存令牌、联系方式或题目答案；成功、退出登录或切换账号后会清理相应数据。网络失败和 429 不会生成新的提交编号，用户可以用原编号手动重试。

历史记录每页 20 条。查看报告只使用服务器返回的 `report_id`，客户端不会根据轮次 ID 猜测报告地址。业务时间由服务端以 UTC 保存，页面日期统一按中国时区显示为 `YYYY-MM-DD`。

## 评分来源与可比性

报告保存评分、报告、目录和各项目引擎版本的完整规则快照。中文词语记忆和视觉记忆锚点属于内部试行训练目标，其余项目显示对应训练规则来源。完成后的历史报告不会随以后规则变更重算。

历史变化只有在引擎、评分规则、语言、输入方式和几何配置一致，且两次结果都没有质量警告时才可比较；否则报告会说明不可比原因。质量警告对应“需复测”，不会参与优势或待提升判断。

## 设备限制

鼠标、触屏、手写笔和混合输入的结果适用条件不同。触屏、手写笔或混合输入本身不是质量错误，也不会单独触发“需复测”；报告会单独提示设备适用性。后台切换、未知输入或服务端识别的协议内异常会形成质量警告。游戏区域几何发生变化或页面隐藏时，本次未完成游戏会中止并要求重新开始。
