# ERP 双主题整体界面设计

## 授权与目标
用户选择 A、B 两套整体 UI，并明确由超级管理员统一设置、所有用户跟随，要求立即开始开发。默认 A 为本次实施选择，不是新增用户偏好。保留同一套业务逻辑，不复制两套 ERP。

## 两套视觉体系
- A「清爽专业」：雾白画布、白色导航、墨色文字、青绿主色、轻边框、柔和圆角、清楚的信息分区。
- B「深蓝效率」：深海军蓝导航、浅色工作区、蓝色主色、更紧凑的桌面密度、连接式统计条、明确的操作层级。不是仅替换主色。
- 品牌统一「竞学 ERP」。所有角色保留现有权限导航。小屏抽屉、底部导航、安全区、44px 交互目标保持可用。
- 覆盖登录、注册、工作台、房态、人员、资产、采购、财务、教学、队伍、评价、餐饮、报表、设置、运维。评测场地、刺激颜色、目标几何、计时与评分不修改；其外围页面与报告统一设计。
- 已入住红色、可入住绿色、待核对/保洁警示色、维修中性色，始终配合文字，不仅依赖颜色。

## 全局配置
主题 ID 为 `clear` / `command`。HTML 根节点 `data-ui-theme` 控制视觉，不重建路由、认证、查询缓存或表单。
匿名 GET `/api/v1/appearance` 只返回 `{theme, revision}`，默认 `clear`, revision 1。
超管 GET/PUT `/api/v1/operations/appearance`，PUT `{theme, expected_revision}`。专用 `operations.appearance.manage` 权限且实际角色必须为 super_admin；普通管理员不能获此能力。写入事务重新校验当前账号与授权，版本冲突返回 409，审计保留旧/新主题、操作人及请求标识。
数据库 singleton 保存全局设置；升级预置默认记录，迁移/备份可携带。只允许两个枚举值，不接受 CSS、HTML 或外部资源地址。
运维监控加入「系统外观」卡片：两张真实风格预览、当前全局标记、选择并保存、取消。编辑选择仅影响卡片预览，保存成功才改变本页；未保存不影响其他用户。清楚提示「全体用户统一使用」。
前端启动快速使用验证过的视觉缓存或 A，再后台读取服务器配置；缓存不能成为权限依据。可见页每 60 秒及重新聚焦刷新公共外观，无轮询隐藏页，不影响业务请求或输入。服务器失败保留当前视觉，不阻断登录。跨请求旧版本不得覆盖新版本。缓存格式有版本，异常/存储不可用可安全回退。
使用打包外部模块，不加内联脚本，不放宽 CSP；同步浏览器 theme-color。切换不强制整页刷新。

## 范围边界与验收
不改变权限、业务数据、上传、财务、住宿规则、评分、路由懒加载和更新保护。主题差异只在展示层。原生 iOS 源码不在本工作区，不宣称生成新安装包。
校验 API 越权/CSRF/持久化/冲突/迁移，前端刷新恢复/同步/失败降级/输入保留；两主题桌面与手机布局、关键对话框、导航焦点及无横向溢出。保留静态资源兼容部署流程。
本地回归通过后必须运行标准 NAS 发布脚本，发布失败视为阻断；不通过直接复制绕过。
