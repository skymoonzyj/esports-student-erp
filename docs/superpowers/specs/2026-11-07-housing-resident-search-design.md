# 房间搜索支持姓名与昵称

用户已确认同一搜索框增加姓名、昵称并要求开始实施。仅匹配当前入住（含待确认退房）人员的完整或部分姓名/昵称；预约、已退房、取消及作废历史不参与人名匹配。保留房号、楼栋、楼层搜索。

采用扩展现有服务端房态筛选，不新增搜索入口或前端当前页过滤。现有房间权限过滤先执行；姓名匹配先于统计和分页。楼栋、楼层等左侧条件保留，顶部统计随左侧搜索变化，顶部快捷筛选仅影响房间列表。

复用现有批量住宿投影查询，读取当前入住人员昵称并保存在内部投影，不新增人员信息响应字段、数据库迁移、依赖或逐房间查询。姓名与昵称按字面子串、Unicode NFKC及不区分大小写匹配；不宣称拼音/首字母搜索。

前端保留“搜索房间”标签、输入法处理和250毫秒防抖，仅补充提示“房号、楼栋、楼层、入住人姓名或昵称”。完成回归、独立复核后按标准脚本同步NAS。
