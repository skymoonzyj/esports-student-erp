# 租用资产批量新增与电脑配置

## 已确认范围

用户选择推荐方案：租用资产按同型号和数量批量创建，每台独立编号、二维码和使用记录；自有或租用电脑记录 CPU、内存、GPU、硬盘容量；历史电脑保留并提示待补充。

## 行为

- 在资产管理提供“批量新增租用资产”，数量为整数 1–100。同一批次共用名称、分类、品牌、型号、位置、租期、备注及电脑配置。
- 每台建立独立资产，沿用现有编码、二维码、分配、续租、退租流程。初始为可用、未分配，不新增权限。
- 创建为原子事务，UUID 操作键和请求摘要防止网络重试造成重复。相同用户、相同键、相同参数返回原批次；参数变化返回 409；回放也验证当前权限。失败不留下部分资产或审计。
- 批量不复制序列号或照片；界面明确提示创建后在单台编辑中补充。单台创建和照片流程保留。
- 电脑类别为现有“台式电脑”“笔记本电脑”。新增这两类时要求四项非空配置，无论自有、租用、采购转入。
- 字段 `cpu_model`（最多 120 字）、`memory_capacity`（最多 80 字）、`gpu_model`（最多 120 字）、`disk_capacity`（最多 120 字）。容量带单位自由文本，例如 32GB、1TB SSD + 2TB HDD；允许 GPU 填“核显”或“无独显”。不推算、不虚构容量。
- 四字段允许 NULL 以兼容历史数据，空白规范化为 NULL。不按资产名称猜测类别，非电脑不强制填写。
- 历史电脑未补齐时可继续修改非配置信息；变更为电脑类别、或修改电脑配置时要求最终四项齐全。现有电脑的完整配置不允许通过空字符串清除。
- 资产管理、个人资产、人员档案资产、扫码详情展示配置；历史缺项显示“待补充”，非电脑没有无意义的缺项提示。
- 导出在现有列之后追加四项配置，沿用 CSV/XLSX 公式注入防护；不改变旧列、权限及隐私边界。
- 采购转资产在勾选加入资产、选择电脑类别时显示同样配置输入，并传递给每台资产；未加入资产不携带配置。

## 安全与发布

- 管理权限沿用行政/超管等现有授权，不扩权；批次读写及回放验证登录会话和当前全局管理权限。
- 租期、取得方式、分类、保修规则沿用现有实现。旧数据不自动重分类，不改历史租赁和领用。
- 仅在隔离环境使用虚拟测试数据；不在 NAS 创建演示资产。
- 保留当前工作树所有既有改动，不提交混合历史；运行测试和独立代码复核后仅通过 `scripts/deploy-nas.sh --source "$PWD"` 发布，失败即阻断发布。
